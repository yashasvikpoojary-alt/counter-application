# Counter Application

A simple and interactive Counter Application built using React.

## 🌐 Live Demo

[View Counter Application](https://counter-application-4380.onrender.com)

## ✨ Features

- Increase the counter
- Decrease the counter
- Reset the counter
- Displays counter status
- Simple and attractive user interface
- Responsive design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- React

## 🚀 Deployment

The application is deployed using Render.
